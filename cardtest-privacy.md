# CardSure — Privacy Policy

_Last updated: October 28, 2026_

CardSure ("the app") is a Windows app that checks whether a USB flash drive or memory card really has the capacity it reports, and measures how fast it reads and writes.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Your drives and files:** the app lists the drives connected to your PC (drive letter, volume label, file system, size and free space) so you can choose one to test. When you start a test, it writes test files only into its own folder named `CardSure-test` on the drive you chose, reads them back to check them, and then deletes them (unless you choose to keep them for a later re-check). It never opens, reads, changes or deletes any other file on the drive, and it never offers the Windows system drive for testing. Test files contain only generated test data, nothing from your PC.

**Reports and history:** if you save a test report (Pro), it is written only to the place you choose, and contains the test results and the drive's name and size. The list of past tests (drive name, file system, size, date and results) is kept in your Windows user profile (AppData) on this PC; you can clear it in the app at any time.

**Network:** the app does not need an internet connection to work and never sends test results or drive information anywhere. Purchases of the optional "Pro" upgrade are handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Local data:** the app stores its settings, the test history and a small diagnostic log in your Windows user profile (AppData). Uninstalling the app removes them. The log never contains file names, folder paths or drive labels — only counts, durations and error codes.

**Children:** the app does not knowingly collect information from anyone, including children.

**Changes:** if this policy changes, the updated version will be published at this address with a new date.
