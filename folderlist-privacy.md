# Dirwell — Privacy Policy

_Last updated: November 10, 2026_

Dirwell ("the app") is a Windows app that lists the files and folders inside a folder you choose and saves that list as a CSV, Excel or HTML file.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Your files:** the app only scans folders you choose, drag in or open with it. For each item it reads the name, size, dates and attributes from Windows; it does not open your files, except in Pro when you ask it to calculate SHA-256 or MD5 hashes, which reads the content of the listed files on your device to compute them. Your files are never changed, moved or uploaded. Exported lists and saved scans (.dirscan files, which contain the folder path, file paths, sizes, dates and any hashes you calculated) are written only to the location you choose, and never overwrite an existing file. In Pro, if you confirm, empty folders you select are moved to the Windows Recycle Bin, where you can restore them.

**Network:** the app does not need an internet connection and does not send anything over the network. Purchases of the optional "Pro" upgrade are handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Local data:** the app stores its settings (which columns you show, the export format and the CSV separator) and a small diagnostic log in your Windows user profile (AppData), only on this PC. Uninstalling the app removes them. The scan results are kept in memory only while the app is open. The log never contains file names, folder paths or file contents.

**Children:** the app does not knowingly collect information from anyone, including children.

**Changes:** if this policy changes, the updated version will be published at this address with a new date.
