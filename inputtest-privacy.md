# Tactwell — Privacy Policy

_Last updated: November 10, 2026_

Tactwell ("the app") is a Windows app that tests keyboards and mice: it shows which keys and buttons respond, finds keys that repeat by themselves, and measures how often a mouse reports its position.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Keyboard and mouse input:** the app reads key presses and mouse input only while its own window is in front, using the Windows Raw Input API. It has no global keyboard or mouse hook and cannot see what you type in other apps. While you test, the app keeps only counts for each key or button in memory (how many times it was pressed and how many repeats were detected). It does not keep the text you type or the order of your key presses, and it never writes them to disk. Closing the app discards these counts.

**Reports (Pro):** if you choose to save a report, the app writes a text or CSV file to the folder you pick. The report contains counts per key and mouse measurements. It does not contain what you typed or the order of key presses.

**Your files:** the app does not open or read any of your files. It only creates a report file when you ask it to.

**Network:** the app does not need an internet connection to work. Purchases of the optional "Pro" upgrade are handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Local data:** the app stores its settings (chosen keyboard map and thresholds) and a small diagnostic log in your Windows user profile (AppData). Uninstalling the app removes them. The log never contains key presses, file names or file contents.

**Children:** the app does not knowingly collect information from anyone, including children.

**Changes:** if this policy changes, the updated version will be published at this address with a new date.
