# MailTrove — Privacy Policy

_Last updated: October 22, 2026_

MailTrove ("the app") is a Windows app that opens, searches and prints email files (.mbox, .mbx, .eml, .msg) stored on your PC.

**What we collect:** nothing. The app does not collect, transmit or sell personal information. It has no account system, no analytics and no advertising, and it never uploads your email anywhere.

**Your email files:** the app only reads the files and folders you open. It never modifies, moves or deletes them. Messages are processed on your PC only.

**Local index (cache):** to reopen large mailboxes quickly, the app stores an index of message headers — sender and recipient names and addresses, subjects, dates, attachment names and Gmail labels — in the app's data folder in your Windows user profile (AppData). Message bodies and attachments are not stored in the index. The index is kept for the 20 most recently used mailboxes (up to about 1 GB) and older entries are deleted automatically. You can delete it at any time from the start screen ("Delete all saved indexes", or "Delete saved index" for one mailbox). Uninstalling the app removes it.

**Attachments you open:** when you click "Open" on an attachment, the file is written to a private temporary folder so that your default app can open it, and it is deleted when MailTrove closes (files still in use are removed the next time). Saved and opened attachments are marked as downloaded from the internet (Windows "Mark of the Web") so that Windows and Office can check them.

**Images from the internet and links:** messages are shown with scripts disabled and all internet requests blocked. If you click "Show images" for a message, the app loads that message's remote images; the sender's server may then learn your IP address and the time you opened the message. This choice applies only to that message and is not remembered. Links in messages open in your default browser only after you confirm.

**Other local data:** your settings (recent files, layout, last folders used) and a small diagnostic log are stored in your Windows user profile (AppData). The log does not contain message content.

**Purchases:** the optional "Pro" upgrade is handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details. This is the only network access the app makes on its own. The Microsoft Edge WebView2 component that displays messages may make routine connections of its own (for example DNS checks or updates); these never include your messages. Internet content inside messages stays blocked as described above.

**Third-party components:** MimeKit (MIT), MsgReader (MIT) with OpenMcdf (MPL-2.0) and UTF-unknown (MPL-1.1), RtfPipe (MIT), Microsoft Edge WebView2 SDK (BSD-3-Clause) and WPF-UI (MIT). The MPL-licensed components are used unmodified; their source code is available at https://github.com/ironfede/openmcdf and https://github.com/CharsetDetector/UTF-unknown.

**Children:** the app does not knowingly collect information from anyone, including children.
