# Bracketwell — Privacy Policy

_Last updated: November 10, 2026_

Bracketwell ("the app") is a Windows app for viewing, searching and querying JSON and NDJSON files that are already on your computer.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Your files:** the app only opens the files you choose, drag in, paste or open with it. They are read only on your device and are never changed, moved or uploaded. Format, minify and CSV export write a new file only to the location you choose. JSON you paste is saved to a temporary file inside the app's own data folder so it can be read; that file is deleted when you close it. If the app is closed unexpectedly, it is removed the next time the app starts, a day or more later.

**Network:** the app does not need an internet connection and does not send anything over the network. Purchases of the optional "Pro" upgrade are handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Local data:** the app stores the following in your Windows user profile (AppData), only on this PC: its settings, a small diagnostic log, and, in Pro, your bookmarks as JSON paths together with a scrambled identifier of the file they belong to (a hash, not the file name or location). Uninstalling the app removes all of it. The log never contains file names, folder paths or file contents.

**Children:** the app does not knowingly collect information from anyone, including children.

**Changes:** if this policy changes, the updated version will be published at this address with a new date.
