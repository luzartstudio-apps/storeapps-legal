# FloatPane — Privacy Policy

_Last updated: October 28, 2026_

FloatPane ("the app") is a Windows app that keeps chosen windows always on top, makes them see-through, and (with the optional Pro upgrade) shows live picture-in-picture mini views of other windows.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Windows on your PC:** to show its list of open windows, the app reads the title, icon and program name of the windows that are open on your PC. This information stays in memory on your PC, is only shown to you inside the app, and is never written to disk or sent anywhere. When you pin a window or change its opacity, the app changes only that window's "always on top" and transparency settings, remembers the original settings, and puts them back when you unpin it, when you quit, or when the window closes. So that it can still put windows back if it is closed unexpectedly (for example a power cut), the app keeps a small local list of the windows it has changed (the program name and a window handle number, never the window title or contents); the list is cleared when the windows are restored. If you create auto-pin rules (Pro), the program names you choose are saved in the app's settings.

**Mini views (Pro):** the live picture-in-picture view is drawn directly by Windows (Desktop Window Manager). The app does not capture, record, save or read the contents of any window or of your screen. The app does not read what you type and does not use keyboard or mouse hooks; its shortcuts are registered with the standard Windows hotkey feature.

**Network:** the app does not need or use an internet connection. Purchases of the optional "Pro" upgrade are handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Local data:** the app stores its settings (shortcuts, options, auto-pin rules), the small restore list described above and a small diagnostic log in your Windows user profile (AppData). Uninstalling the app removes them. The log never contains window titles, file names or window contents.

**Children:** the app does not knowingly collect information from anyone, including children.
