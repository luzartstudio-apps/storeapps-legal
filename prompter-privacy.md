# Prompter — Privacy Policy

_Last updated: October 20, 2026_

Prompter ("the app") is a Windows teleprompter app.

**What we collect:** nothing. The app does not collect, store, transmit or sell personal information. It has no account system, no analytics and no advertising.

**Your scripts:** scripts you write or open are stored only on your PC, in your Windows user profile (AppData). They are never uploaded.

**Phone remote (Pro):** if you turn on "Control from phone", the app runs a small web server on your PC while the prompter window is open. It listens only on your local (private) network and accepts only requests that carry the random security code shown in the QR code for that session. The phone can only send scroll commands (play, pause, speed, jump) and read the scroll position — it cannot read your script. Nothing is sent to the internet. While the QR code is displayed, the prompter window is hidden from screen sharing and recordings so the code is not exposed.

**Local data:** the app stores settings, scripts and a small diagnostic log in AppData. The log does not contain your scripts or the security code. Uninstalling the app removes this data.

**Purchases:** the optional "Pro" upgrade is handled entirely by the Microsoft Store under Microsoft's privacy statement (https://privacy.microsoft.com/privacystatement); we never see your payment details.

**Children:** the app does not knowingly collect information from anyone, including children.

**Changes:** if this policy changes, the updated version will be published at this address with a new date.
